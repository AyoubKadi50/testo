## Install Open Claude (free-claude-code)

If you want to install and run the open Claude CLI from this project:

```bash
git clone https://github.com/Alishahryar1/free-claude-code.git
cd free-claude-code
npm install
npm run build
npm start
```

If the project provides a different start command, use the command listed in its `README.md`.
